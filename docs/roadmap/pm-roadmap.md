# PM开发路线

## Week 1：基础设施与框架搭建

### Day 1（周一）
**目标**：搭建项目管理框架

- [ ] **上午**：创建GitHub Projects看板

  - 添加Week 1所有任务
  - 设置标签：backend / frontend / data / docs

- [ ] **下午**：编写项目启动文档

### Day 2（周二）

## 里程碑定义

### Milestone 1：基础设施（Week 1结束）

| 检查项 | 标准 | 负责人 |
|--------|------|--------|
| Docker环境 | `docker-compose up -d` 一键启动 | 后端 |
| 后端服务 | `http://localhost:8000/health` 返回200 | 后端 |
| 前端服务 | `http://localhost:5173` 可访问 | 前端 |
| 数据库 | Neo4j、Redis、ChromaDB正常运行 | 后端 |
| 爬虫 | 能爬取并解析维基百科页面 | 数据 |
| 测试数据 | Neo4j中有10个艺人数据 | 数据 |

### Milestone 2：MVP（Week 2结束）

| 检查项 | 标准 | 负责人 |
|--------|------|--------|
| 搜索功能 | 能搜索并返回结果 | 前端+后端 |
| 人物详情 | 能查看人物基本信息 | 前端+后端 |
| 对话功能 | 能进行简单问答 | 后端 |
| API响应 | P95 < 3s | 后端 |
| 数据量 | 100个艺人 | 数据 |

### Milestone 3：功能完善（Week 3结束）

| 检查项 | 标准 | 负责人 |
|--------|------|--------|
| 对话优化 | 支持多轮对话、上下文理解 | 后端 |
| 关系图谱 | 可视化展示人物关系 | 前端 |
| 领域浏览 | 按领域浏览艺人 | 前端+后端 |
| 数据质量 | 完整率 ≥ 95% | 数据 |

### Milestone 4：扩展优化（Week 5结束）

| 检查项 | 标准 | 负责人 |
|--------|------|--------|
| 后台管理 | 基础CRUD功能 | 前端+后端 |
| 性能优化 | P95 < 2s | 后端 |
| 测试覆盖 | 单元测试 ≥ 80% | 后端+前端 |
| 数据量 | 500个艺人 | 数据 |

## 风险登记册

| 风险 | 可能性 | 影响 | 应对措施 |
|------|--------|------|---------|
| LLM API不稳定 | 中 | 高 | 实现重试机制，准备降级方案 |
| 维基百科反爬 | 中 | 中 | 控制频率，准备代理方案 |
| 前端D3.js复杂 | 中 | 中 | 预留充足时间，准备简化方案 |
| 需求变更 | 高 | 中 | 变更控制流程，评估影响 |
| 人员不足 | 低 | 高 | 优先级排序，必要时裁剪范围 |
