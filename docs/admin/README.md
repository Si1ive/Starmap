## 快速概览

### 功能模块

```
后台管理端
├── 🏠 数据看板（Dashboard）
│   └── 核心指标 / 趋势图表 / 实时监控
│
├── 👤 艺人管理
│   ├── 艺人列表（搜索/筛选/分页）
│   ├── 艺人详情
│   ├── 新增/编辑艺人
│   └── 批量导入/导出
│
├── 🎬 作品管理
│   ├── 作品列表
│   └── 作品编辑
│
├── 🕷️ 爬虫管理
│   ├── 任务列表
│   ├── 任务控制（启动/停止）
│   ├── 实时日志
│   └── 爬虫配置
│
├── 💬 对话管理
│   ├── 对话记录
│   ├── 对话详情
│   └── 热门问题分析
│
├── 📊 系统监控
│   ├── API性能监控
│   ├── 数据库状态
│   └── 错误日志
│
└── ⚙️ 系统配置
    ├── LLM配置
    ├── 搜索配置
    ├── 爬虫配置
    └── 用户管理
```

### 用户角色

| 角色 | 权限级别 | 说明 |
|------|----------|------|
| **超级管理员** | L3 | 全部权限，包括用户管理、系统配置 |
| **数据管理员** | L2 | 数据管理、爬虫控制、数据质量查看 |
| **运营人员** | L1 | 查看数据、对话日志、基础报表 |

### 开发时间

- **Week 4-5**：开发实现
- **Week 5 Day 14**：PM验收

### 技术栈

| 层级 | 技术 |
|------|------|
| 前端 | React 18 + TypeScript + Vite + Ant Design Pro |
| 后端 | FastAPI + JWT + Redis |
| 图表 | ECharts |
| 实时通信 | WebSocket |
