## 1. 产品概述

### 1.1 产品定位

StarMap后台管理端是面向**系统管理员**和**数据运营人员**的管理平台，用于：
- 管理艺人数据（增删改查、审核）
- 监控爬虫任务和数据采集状态
- 查看系统运行指标和对话日志
- 配置系统参数和LLM模型

### 1.2 用户角色

| 角色 | 权限级别 | 说明 |
|------|----------|------|
| **超级管理员** | L3 | 全部权限，包括用户管理、系统配置 |
| **数据管理员** | L2 | 数据管理、爬虫控制、数据质量查看 |
| **运营人员** | L1 | 查看数据、对话日志、基础报表 |

### 1.3 价值主张

- **数据可控**：管理员可手动修正爬虫错误数据
- **任务可管**：实时监控爬虫进度，异常及时处理
- **系统可观**：全面掌握系统运行状态和用户行为
- **配置可调**：灵活调整LLM参数、搜索权重等

## 3. 模块详细设计

### 3.1 数据看板（Dashboard）

**页面**：`/admin/dashboard`

**功能描述**：
展示系统核心运营指标，帮助管理员快速了解系统状态。

**展示内容**：

| 指标卡片 | 数据说明 | 更新频率 |
|----------|----------|----------|
| 艺人总数 | Neo4j中Person节点数量 | 实时 |
| 作品总数 | Neo4j中Work节点数量 | 实时 |
| 关系总数 | Neo4j中Relation边数量 | 实时 |
| 今日对话数 | 当日Chat API调用次数 | 实时 |
| 数据完整率 | 字段非空比例 | 每小时 |
| API平均响应 | 最近1小时P95响应时间 | 实时 |

**图表**：
- 近7日对话量趋势图（折线图）
- 艺人分类分布（饼图）
- 热门搜索词Top10（柱状图）
- 爬虫任务状态（进度条）

### 3.2 艺人管理（Person Management）

**页面**：
- 列表：`/admin/persons`
- 详情：`/admin/persons/:id`
- 编辑：`/admin/persons/:id/edit`
- 新增：`/admin/persons/new`

**功能描述**：
对艺人数据进行全生命周期管理。

**列表页功能**：

| 功能 | 说明 |
|------|------|
| 搜索 | 按姓名、英文名、ID搜索 |
| 筛选 | 按分类、国籍、性别、数据状态筛选 |
| 排序 | 按姓名、创建时间、更新时间排序 |
| 分页 | 每页20/50/100条 |
| 批量操作 | 批量删除、批量导出 |
| 快速编辑 |  inline编辑常用字段 |

**列表字段**：

| 字段 | 说明 | 可排序 |
|------|------|--------|
| ID | 艺人唯一标识 | ✅ |
| 头像 | 缩略图 | ❌ |
| 姓名 | 中文名 | ✅ |
| 英文名 | 英文/拼音名 | ✅ |
| 分类 | 演员/歌手/导演等标签 | ❌ |
| 国籍 | 中国/美国/日本等 | ✅ |
| 数据来源 | 维基百科/手动录入 | ✅ |
| 数据状态 | 完整/部分/待审核 | ✅ |
| 创建时间 | 数据入库时间 | ✅ |
| 更新时间 | 最后修改时间 | ✅ |
| 操作 | 查看/编辑/删除 | ❌ |

**详情页功能**：
- 基本信息展示（所有字段）
- 作品列表（关联作品）
- 关系图谱（简化版，展示直接关系）
- 编辑历史（修改记录）
- 操作按钮：编辑、删除、刷新数据

**编辑页字段**：

```
基本信息
├── 姓名*（文本）
├── 英文名（文本）
├── 头像（图片上传）
├── 性别（单选：男/女/未知）
├── 出生日期（日期选择器）
├── 出生地点（文本）
├── 国籍（下拉选择）
├── 身高（数字，cm）
├── 职业分类（多选标签）
├── 摘要（多行文本）
└── 详细传记（富文本编辑器）

扩展信息
├── 代表作品（关联作品多选）
├── 社交媒体（微博/Instagram/Twitter链接）
├── 获奖记录（动态表格）
```

### 3.4 爬虫管理（Crawler Management）

**页面**：
- 任务列表：`/admin/crawler`
- 任务详情：`/admin/crawler/:taskId`
- 配置页：`/admin/crawler/config`

**功能描述**：
管理和监控数据采集任务。

**任务列表字段**：

| 字段 | 说明 |
|------|------|
| 任务ID | 唯一标识 |
| 任务类型 | 全量爬取/增量更新/定向爬取 |
| 目标数据源 | 维基百科/豆瓣/其他 |
| 目标数量 | 计划爬取数量 |
| 已完成数量 | 实际完成数量 |
| 成功数 | 成功爬取的条目数 |
| 失败数 | 爬取失败的条目数 |
| 成功率 | 成功数/已完成数 |
| 进度 | 百分比进度条 |
| 状态 | 待启动/运行中/已完成/失败/已停止 |
| 开始时间 | 任务启动时间 |
| 预计完成 | 基于当前速度的预估 |
| 操作 | 启动/停止/查看日志/删除 |

**任务操作**：

| 操作 | 说明 | 权限 |
|------|------|------|
| 启动任务 | 开始新的爬取任务 | L2+ |
| 停止任务 | 中断正在运行的任务 | L2+ |
| 查看日志 | 查看实时/历史日志 | L1+ |
| 查看统计 | 查看爬取详细统计 | L1+ |
| 重新运行 | 对失败任务重新执行 | L2+ |
| 删除任务 | 删除任务记录 | L3 |

**爬虫配置项**：

```
基础配置
├── 请求间隔（秒，默认1.0）
├── 超时时间（秒，默认30）
├── 最大重试次数（默认3）
├── User-Agent轮换（开关）
└── 代理设置（可选）

高级配置
├── 并发数限制
├── 每日爬取上限
├── 失败重试策略
├── 数据去重规则
└── 自动清洗开关
```

| 整体成功率 | 总成功数/总爬取数 | 实时 |
| 今日爬取数 | 当日新增爬取条目数 | 实时 |

#### 2. 任务执行统计

| 指标 | 说明 |

| 待启动任务数 | 排队等待执行的任务 |
| 今日完成任务数 | 今日已完成的任务 |
| 今日失败任务数 | 今日失败的任务 |
| 平均任务耗时 | 最近7天任务平均执行时间 |

| 数据源成功率对比 | 各数据源的成功率对比 |

#### 4. 失败分析

| 最近爬取记录 | 最近10条爬取记录 |

**图表展示**：
- 近7日爬取量趋势图（折线图，分成功/失败）

### 3.4.2 爬取日志详情（Crawler Log Detail）

**页面**：`/admin/crawler/:taskId/logs`

**功能描述**：
查看单个任务的详细爬取日志，支持实时推送和历史查询。

**日志字段**：

| 字段 | 说明 |
|------|------|
| 时间戳 | 日志产生时间 |
| 级别 | INFO/WARNING/ERROR/DEBUG |
| 资源URL | 爬取的目标URL |
| 资源名称 | 艺人/作品名称 |
| 操作 | 下载/解析/存储/跳过 |
| 状态 | 成功/失败/重试 |
| 耗时 | 该步骤耗时(ms) |
| 消息 | 详细日志内容 |
| 错误类型 | 超时/404/反爬/解析错误等 |

**日志筛选**：
- 按级别筛选（INFO/WARNING/ERROR）
- 按状态筛选（成功/失败/重试）
- 按错误类型筛选
- 按时间范围筛选
- 按资源名称搜索

**实时日志**：
- WebSocket实时推送
- 自动滚动到底部
- 高亮ERROR级别日志
- 支持暂停/继续接收

## 5. 交互设计

### 5.1 通用交互规范

| 操作 | 交互方式 | 反馈 |
|------|----------|------|
| 保存 | 主按钮（蓝色） | Toast提示"保存成功" |
| 删除 | 危险按钮（红色）+ 二次确认弹窗 | Toast提示"删除成功" |
| 搜索 | 输入框 + 回车/搜索按钮 | 实时加载结果 |
| 筛选 | 下拉选择/日期范围 | 自动刷新列表 |
| 分页 | 底部分页器 | 保持筛选条件 |
| 批量操作 | 复选框 + 顶部批量操作栏 | 显示选中数量 |
