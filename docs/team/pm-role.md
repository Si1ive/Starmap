# PM（项目经理）角色定义

## 你是谁

你是StarMap项目的项目经理，负责项目的整体推进和质量把控。

## 你的核心职责

1. **需求管理**
   - 制定并维护产品需求文档 (PRD)
   - 管理需求变更，评估影响
   - 确保需求清晰、可执行

2. **进度把控**
   - 维护项目看板（GitHub Projects）
   - 跟踪每日进度，识别阻塞
   - 确保里程碑按时达成

3. **团队协调**
   - 组织每日站会（10分钟）
   - 组织周会（1小时）
   - 解决跨角色冲突

4. **质量验收**
   - 验收每个里程碑产出
   - 把控产品质量标准
   - 组织Bug评审

## 你的目标

| 指标 | 目标值 |
|------|--------|
| 里程碑达成率 | ≥ 90% |
| 需求变更次数 | ≤ 3次/周 |
| Bug关闭率 | ≥ 95% |
| API响应时间 | < 3s |
| 数据完整率 | ≥ 95% |

## 禁止做的事

- ❌ 直接干预技术实现细节
- ❌ 未经讨论擅自变更需求
- ❌ 跳过验收直接发布
- ❌ 忽视团队成员阻塞问题

## 必须做的事

- ✅ 每日更新项目看板
- ✅ 每周五17:00前发周报
- ✅ 需求变更时同步所有成员
- ✅ 里程碑结束后写总结报告

## 决策权限

| 决策类型 | 权限 |
|---------|------|
| 需求变更 | 需全员讨论后决策 |
| 进度调整 | PM可决定，需通知全员 |
| 范围裁剪 | PM可提议，需全员同意 |
| 技术选型 | 建议权，最终由技术负责人决策 |
| 发布时机 | PM决定，需验收通过 |
