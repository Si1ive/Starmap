# 多会话协作规范

## 核心原则

1. **每个会话独立** - 不同对话的上下文是隔离的
2. **文档是桥梁** - 通过文件系统同步信息
3. **CHANGELOG是真相源** - 所有跨角色变更必须记录

## 启动流程（必须执行）

### 1. 执行启动脚本

```bash
./scripts/session-start.sh [backend|frontend|data|pm]
```

这会读取：
- 最新 CHANGELOG
- 角色定义文件
- 当前任务列表
- 路线图进度
- Git状态

### 2. 确认理解

回答以下问题：
- 当前任务是什么？
- 其他角色最近做了什么？
- 有什么阻塞问题？

### 3. 声明角色

在对话开始时明确声明：

```
【角色声明】
我是：[backend|frontend|data|pm] 工程师
当前任务：xxx
已读取CHANGELOG：是
```

## 工作规范

### 修改代码前

- [ ] 阅读相关文档
- [ ] 确认不影响其他角色
- [ ] 如有影响，先记录到CHANGELOG

### 修改代码后

- [ ] 自测通过
- [ ] 更新CHANGELOG（如果影响其他角色）
- [ ] 提交代码
- [ ] 记录开发日志

## CHANGELOG 记录规范

### 格式

```markdown
### [会话-角色] 变更标题
- **类型**：feat/fix/docs/refactor/test
- **影响**：影响范围（如影响Frontend，需标注）
- **描述**：
  - 具体变更1
  - 具体变更2
- **注意**：@Frontend 请同步更新搜索页面
```

### 何时记录

| 场景 | 是否记录 | 说明 |
|------|---------|------|
| 修改自己领域代码 | 可选 | 如修改backend的API实现 |
| 修改接口/数据结构 | **必须** | 影响其他角色 |
| 修改配置文件 | **必须** | 可能影响环境 |
| 修改文档 | 建议 | 帮助其他角色了解 |

### 跨角色影响标记

使用 `@角色` 标记需要关注的人：

```markdown
- **注意**：@Frontend 搜索API返回字段有变化
- **注意**：@Backend 需要新增管理员认证接口
- **注意**：@Data 爬虫数据格式需要调整
```

## 同步机制

### 每日同步

每个会话启动时：
1. 执行启动脚本
2. 阅读CHANGELOG
3. 关注标记了 `@自己角色` 的记录

### 紧急同步

重大变更立即记录：
1. 修改代码
2. 立即更新CHANGELOG
3. 在记录中 @ 相关角色

## 检查清单

### 会话启动检查清单

- [ ] 执行启动脚本 `./scripts/session-start.sh [角色]`
- [ ] 阅读CHANGELOG最新记录
- [ ] 确认当前任务和优先级
- [ ] 检查Git分支和工作区状态

### 工作完成检查清单

- [ ] 代码自测通过
- [ ] 更新CHANGELOG（如影响其他角色）
- [ ] 提交代码并推送到远程
- [ ] 记录开发日志（docs/logs/[角色]-log.md）

## 常见问题

### Q: 我忘了执行启动脚本怎么办？

A: 立即停止当前工作，执行启动脚本，确认没有遗漏重要变更。

### Q: 我发现CHANGELOG没有及时更新怎么办？

A: 
1. 先更新CHANGELOG，补充遗漏的变更
2. 通知相关角色
3. 以后严格遵守规范

### Q: 多个角色同时修改同一文件怎么办？

A:
1. 先沟通确认分工
2. 使用不同的Git分支
3. 合并时仔细解决冲突

## 示例流程

### 后端工程师的一天

```bash
# 1. 启动会话
./scripts/session-start.sh backend

# 2. 阅读CHANGELOG，了解前端昨天修改了搜索页面

# 3. 开始工作：实现搜索API

# 4. 工作完成后：
#    - 自测通过
#    - 更新CHANGELOG：
#      "### [会话-Backend] 实现搜索API
#       - **类型**：feat
#       - **影响**：Frontend（需要对接）
#       - **注意**：@Frontend 搜索API已就绪，路径 /api/v1/persons/search"
#    - 提交代码
#    - 记录开发日志
```

### 前端工程师的一天

```bash
# 1. 启动会话
./scripts/session-start.sh frontend

# 2. 阅读CHANGELOG，发现Backend标记了@Frontend
#    "搜索API已就绪"

# 3. 开始工作：对接搜索API

# 4. 工作完成后：
#    - 自测通过
#    - 更新CHANGELOG
#    - 提交代码
#    - 记录开发日志
```
