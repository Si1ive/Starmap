## 决策记录

| 日期 | 决策 | 原因 |
|------|------|------|
| 2026-06-08 | 项目定位转为"408考研学习平台" | 408考研有明确受众和痛点 |
| 2026-06-08 | 采用RAG架构而非简单搜索 | 需要基于知识库的精准回答 |
| 2026-06-08 | 采用 MySQL+Qdrant+Redis 主数据架构 | 结构化存储、检索索引与缓存职责清晰 |
| 2026-06-18 | 大纲独立入库，走标题树而非题目抽取 | 大纲结构与题目文档结构不同 |
| 2026-06-23 | 大纲拆分改为两轮（骨架+增强） | 解决 LLM max_tokens 截断 |
| 2026-06-25 | 跨章关联收敛到考点级 | 章节级关联过粗，考点级更精准 |
| 2026-07-01 | 题目提取改为纯 bbox 坐标分组 | 坐标是 MinerU 输出唯一稳定信号，文本定位对 OCR 噪声/跨页/嵌套不可靠 |
