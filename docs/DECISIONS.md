## 已完成的决策

### 2026-06-02：技术选型

**背景**：项目初始化，需要确定技术栈

**选项**：
- 选项A：React + Django（全栈Python）
- 选项B：React + FastAPI（前后端分离）

**决策**：选择选项B

**原因**：
- 团队对FastAPI更熟悉
- 前后端分离便于并行开发
- FastAPI自动生成API文档

**影响**：
- 前端使用React + Vite
- 后端使用FastAPI
- 需要定义清晰的接口规范

**负责人**：Backend + Frontend

---

### 2026-06-02：数据库选择

**背景**：需要存储图数据、向量数据、缓存数据

**选项**：
- 选项A：单一数据库（PostgreSQL + 插件）
- 选项B：多数据库（Neo4j + ChromaDB + Redis）

**决策**：选择选项B

**原因**：
- Neo4j是图数据库首选
- ChromaDB专注向量检索
- Redis适合缓存和会话

**影响**：
- 增加运维复杂度
- 需要Docker Compose编排
- 各数据库需要独立维护

**负责人**：Backend

---

### 2026-06-02：爬虫数据源

**背景**：需要确定艺人数据来源

**选项**：
- 选项A：单一数据源（仅维基百科）
- 选项B：多数据源（维基百科 + 豆瓣 + 其他）

**决策**：MVP用选项A，后续扩展选项B

**原因**：
- 维基百科数据结构化程度高
- 先验证核心流程再扩展

**影响**：
- MVP阶段数据量有限
- 需要设计可扩展的爬虫框架

**负责人**：Data

### 2026-06-02：Agent方案

**背景**：需要实现对话Agent

**选项**：
- 选项A：使用LangChain（快速，但依赖重）
- 选项B：自研Agent框架（灵活，但工作量大）

**决策**：MVP用选项A，V1.0评估选项B

**原因**：
- 快速验证对话功能
- 减少MVP开发时间

**影响**：
- 依赖LangChain版本
- 后续可能需要重构

**负责人**：Backend

### 2026-06-03：后台管理端规划

**背景**：用户询问后台管理端是否在计划内

**选项**：
- 选项A：保持原计划（Week 4-5简单CRUD）
- 选项B：强化后台管理端（完整功能，独立项目）

**决策**：选择选项B

**原因**：
- 管理员需要完整的数据管理能力
- 爬虫任务需要可视化控制
- 系统监控对运维至关重要
- Frontend进度超前，有资源提前启动

**影响**：
- 增加Week 4-5工作量
- 需要新增前端项目（frontend-admin）
- 需要新增25+后端API
- 需要设计权限系统

**具体方案**：
- 前端：独立React项目，Ant Design Pro组件库
- 后端：独立API模块（/api/v1/admin），JWT认证
- 功能：看板、艺人管理、爬虫管理、对话管理、监控、配置
- 角色：超级管理员(L3)、数据管理员(L2)、运营人员(L1)

**负责人**：PM
